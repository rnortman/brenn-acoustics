This repository has not been published: it has no public remote and its CI workflow has never run. Publishing is the maintainer's work and takes: creating the remote; the branch ruleset, with the CI jobs as required checks; the checks before a first push (a clean scan of the tree, a reading of every dependency's licence, no private reference in any manifest or lock file); the maintainer's review of the text that ships (README, changelog, commit message); the first push, of the main branch alone; and the maintainer's own record-keeping. Done when the repository is on its public remote and its CI has passed there. Whether to reserve the crate's name on the public registry is open, and is decided with the publication. The comment sits at the top of `.github/workflows/ci.yml`.
